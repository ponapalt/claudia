バルーン「クローディア（頭上）」
================================

ゴースト「悪役令嬢クローディア」のための専用バルーンです。
しっぽが真下を向いていて、キャラクターの頭の上に出ます。

・\0（クローディア）側は、象牙色の羊皮紙にテラコッタの縁と金の罫。
・\1（アンソニー）側は、淡い青のカードに燕尾服の縁とブローチの深緑。
・横に出す版が別にあります（「クローディア」）。

画像
----
32bit RGBA PNG。透過はアルファチャンネル（use_self_alpha,1）。
入力ボックスも半透明で描かれます（use_input_alpha,1）。

フォント
--------
本文は等幅の明朝体（BIZ UD明朝 → ＭＳ 明朝 の順に探します）。
半角の英数字も全角のちょうど半分の幅になるので、字の並びがずれません。
入力ボックスは等幅のゴシック体（BIZ UDゴシック → ＭＳ ゴシック）です。
ゴシック体にしたいときは descript.txt の font.name を書き換えてください。
