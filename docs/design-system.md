# クロード公爵家の意匠（デザインシステム）

「悪役令嬢クローディア」の見た目の決まり。クローディア本人の好みを、そのまま規範にしたもの。
画像、バルーン、メニュー、アイコン、サムネイル、HTML のページなど、目に見えるものを作ったり直したりするときに読む。

## 使うとき

作者が次のように頼んだとき。

- 「バルーンの色を変えて」「バルーンを作り直して」「メニューの画像を直して」「アイコンを作って」
- 「サムネイルを作って」「バナーを作って」「リリース用の画像がほしい」
- 「ページを作って」「功績録を HTML にして」など、ゴーストのための Web ページや Artifact
- 「見出しを目立たせて」「称号に色を付けて」など、バルーンの中の文字の装飾

次のものは、この文書では決めない。

- 台詞の中身と口調（`GHOST.md` の「キャラクターとサーフェス」「トークの書き方」）
- 立ち絵の画風（シェルの画像は作者が生成する。頼むときの言葉だけ「絵を頼むとき」に書いた）

## 前提

- 今ある素材は、どれもこの規範で作り直してある（「既存の素材との関係」）。規範を変えても、**頼まれていないのに素材を作り直さない。**
- 他のゴーストのバルーンやメニューの意匠を、似せて描いて持ち込まない（`AGENTS.md` の「AI を使ったゴースト制作のガイドライン」）。
- フォントのファイルを同梱しない。Windows に標準で入っているもの（画像と SSP）か、Web フォント（HTML）だけを使う。
- 画像を作るスクリプトは `work/` に置き、`tools/` のスクリプトと同じく Windows PowerShell 5.1 で動くよう、ASCII 文字だけで書く。

## 着想

**公爵家から届く招待状。**
上質な羊皮紙に、鉄胆インクで書かれた文字。縁には赤土色の枠と、ひと筋の金の罫。封には葡萄酒色の封蝋。
昼は「茶会」（明るい紙の地）、夜は「夜会」（黒葡萄色の地に金）の二つの装いを持つ。

執事アンソニーの持ち物は、お嬢様の招待状に添えられた**銀盆の上の名刺**。冷たい青と銀、飾りは翠のブローチひと粒だけ。

## 七つの作法

1. **紙が主役。余白は富のしるし。** 面積のおよそ 7 割は地のまま残す。詰まってきたら、余白ではなく言葉を削る。
2. **金は線だけ。** 金は細罫、菱、縁取りにだけ使う。金で面を塗らない。金のグラデーションや「きらめき」も描かない。昼の装いでは金を文字の色にしない（読めない）。
3. **飾りは構造に宿る。** 飾りを置いてよいのは、角、区切り、始まりと終わりだけ。何もない場所に飾りを浮かべない。一つの画面に使う飾りは 3 種類まで。
4. **強い色は一か所。** 赤土色の強調は、一つの画面に一か所。二か所目が欲しくなったら、片方を墨にする。
5. **左右対称を基本に、崩すのは一か所。** 崩す場所は右下と決める（透かしのモノグラム、封蝋、署名）。
6. **執事は引き算。** アンソニーの物には、お嬢様の物より飾りを少なくする。銀の細罫一本と翠の菱ひと粒まで。お嬢様より目立たせない。
7. **洒落は小さく隠す。** 透かしの頭文字、封蝋、一輪の薔薇。気づいた人だけが楽しめる大きさと濃さにする。

## 色

色の割合の目安は、**紙 70・墨 20・赤土 8・金 2**。純粋な黒（#000000）と白（#FFFFFF）は使わない。黒は墨か夜会の地、白は羊皮紙で代える。

コントラスト比は WCAG の計算式で求めた値（羊皮紙の地に対して）。4.5 以上なら本文に使える。

## 文字

### 書体

| 役割 | SSP・画像（Windows 標準） | HTML（Google Fonts） |
|---|---|---|
| クローディアの本文 | BIZ UD明朝 Medium（等幅。バルーンはこれ） | BIZ UDPMincho |
| 見出し、題字 | 游明朝 Demibold（Yu Mincho Demibold） | Shippori Mincho B1（600〜800） |
| 欧文の添え書き、頭文字 | Palatino Linotype Italic（無ければ Georgia Italic） | Cormorant Garamond Italic |
| アンソニーの帳簿（数字の表、一覧） | BIZ UDPゴシック | BIZ UDPGothic |

- **声は明朝。** クローディアの言葉と、ゴーストの見出しは明朝で書く。
- **ゴシック体は執事の帳簿だけ。** 数字の並ぶ表、入力欄、細かい一覧にだけゴシック体を使ってよい。クローディアの台詞をゴシック体にしない。
- 欧文はイタリックで、名前と短い添え書きだけに使う（`Claudia`、`et Anthony`、`Le livre des mérites`）。欧文で長い文を書かない。

### 大きさと行間（HTML と画像）

- 段階は 13 / 15 / 18 / 24 / 32 / 44 px。本文は 15〜16px。
- 行の高さは、和文の本文 1.85、見出し 1.4。
- 字間は、見出し 0.12em、本文 0.02em。題字は字間を広く取って品よく見せる。
- 一行は全角 36 字まで（`max-width: 36em` くらい）。
- バルーンの中は `font.height,15` のまま。大きさを変えるのは題だけにし、`\f[height,+3]` まで。

### 約物と数字

- 会話は「」、作品や称号の名前は『』。
- 間は「‥」（トークの書き方に合わせる）。ダッシュは「――」（全角 2 つ）。
- 数字は算用数字で、3 桁ごとにカンマ（功績録の `CCS.Comma` と同じ）。日付は `2026年9月25日`、時刻は `14時05分` か `14:05`。
- 感嘆符は一文に一つまで。「！？」を重ねない。高笑いのときだけは例外。

## 形と間合い

- 間合いの単位は 4px。使う値は 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 角の丸み: 紙（バルーン、ページの枠）14px、カード 10px、ボタンや入力欄 4px。丸いボタン（pill）は使わない。令嬢の持ち物は角がきちんとしている。
- 縁: 外枠は 2px の赤土。その 6px 内側に 1px の金の細罫（透明度 80%）。この**二重枠**が招待状のしるし。小さな部品（ボタン、入力欄）は 1px の枠一本だけ。
- 影は一種類だけ。紙が机から少し浮いたくらい。
  - CSS: `0 1px 2px rgba(58,36,25,.12), 0 8px 24px rgba(58,36,25,.10)`
  - 光る影（glow）、色付きの影、重い落ち影は使わない。
- 地のグラデーションは、上から下へ羊皮紙から生成りへの、紙の陰影だけにする。上端に白い照り（透明度 40% 以下）を入れてよい。

## 飾りの部品

| 部品 | 形 | 使ってよい場所 |
|---|---|---|
| 二重枠 | 上の「縁」のとおり | 紙の外周 |
| 角の菱 | 5×5px の菱（◆）。金 | 二重枠の四隅の、細罫が曲がり始める所 |
| 区切りの菱 | 中央に 11×5px、左右 11px 離して 4×3px を一つずつ。金 | 区切り罫の中央、枠の上辺と下辺の中央 |
| 区切り罫 | 1px の金の線。両端は透明へ消える | 節の区切り。一画面に 2 本まで。画面の端に沿わせない（一本だけの線は描画の乱れに見える） |
| 透かしの頭文字 | イタリックの `C`（アンソニーは `A`）。地の色に対し不透明度 10〜12% | 右下。枠からはみ出して切れてよい |
| 封蝋 | 直径 28〜48px の葡萄酒色の円。縁は少し不揃い。中に羊皮紙色の `C` | 完了、授与、署名の場面。一画面に一つ |
| 一輪の薔薇 | 白薔薇の線画。花びらは羊皮紙色、線は深赤土 | 署名の脇。作品全体でも一輪 |
| 燕尾の切れ込み | 下辺中央の小さな V 字の切り欠き | アンソニーの HTML のカードだけ。バルーンでは試したが、縁がへこんだだけに見えたのでやめた |
| 翠の菱 | 5×5px の翠の菱 | アンソニーの物に一つだけ |

- 文字で書くときの形: 見出しの頭に `◆`、区切りは `―― ◇ ――`（中央寄せ）。絵文字は使わない（バルーンのフォントで表示できず、品もない）。
- 花の縁取り、リボン、ハート、星、きらめきは使わない。

## 媒体ごとの作り方

### バルーン（画像と `descript.txt`）

形の寸法と文字の入る量は `work/balloon/make-balloon.ps1` の先頭のコメントにある。

- **画像の大きさ、本体の形、`descript.txt` の色以外の行（位置、有効範囲、折り返しなど）は変えない。** 1px 単位で合わせてある。色を変えるときは `work/balloon/text/` の `descript.txt` と `kero-override.txt` の `*.color.r/g/b` の行だけを書き換え、`make-balloon.ps1` で作り直す。作り直したら、画像の幅と高さがコミット済みのものと同じか確かめる。
- しっぽは羽根ペンの先の形。辺はつけ根で本体の縁に沿って出て、外へ曲がり、細い先へすぼまる。出っ張りは 8px（本体の外の 9px の余白に収める）。
- しっぽのつけ根の、内側の細罫の上に小さな菱を一つ置く（クローディアは金、アンソニーは銀）。頭上版では下の辺の中央の菱の代わりになる。

### バルーンの中の文字の装飾

さくらスクリプトの `\f[...]` で装飾する。**装飾は見出しと称号だけ**にし、台詞の途中では使わない。装飾したら必ず `\f[default]` で戻す。

| 使いどころ | 書き方 |
|---|---|
| 頁の題（功績録など） | `\f[color,140,59,31]\f[bold,1]◆ 功績録\f[default]` |
| 称号の名前 | `\f[color,109,31,44]『深夜の宰相』\f[default]` |
| 補足の小さな注記 | `\f[color,107,78,61]（午前 4 時で区切りますわ）\f[default]` |
| 区切り | `\f[align,center]―― ◇ ――\n\f[align,left]`（SSP 2.5.31 以降） |

- 太字は、フォントが対応していないと太くならない（UKADOC の `\f[bold]`）。BIZ UD明朝 Medium で太く見えるかは、試験用 SSP で `tools/sstp.ps1 -Script '...' -Balloon` を使って確かめる。
- アンソニーの台詞の強調は藍 `52,86,168`。封蝋の色はお嬢様だけが使う。
- 一つのトークで色を変えるのは 2 か所まで。

### オーナードローメニュー

画像は `work/menu/make-menu.ps1`、文字の色は `yaya_string.dic` の `MenuColor`、書体はゴーストの `descript.txt` の `menu.font.name` にある。

- 画像は `leftbottom`（サイドバーは `bottom`）で置く。メニューが画像より大きいと、SSP は右へは各行の右端の色を、上へは各列の上端の色を延ばす。延びて困る飾りは、右端と上端に置かない。
- 画像の高さは 1024px。SSP のメニューは項目が多いので、延ばしに頼らずに収まる高さにしておく。
- 書体は BIZ UDP明朝 Medium（声は明朝）。`menu.font.name` はゴースト全体で一つなので、アンソニーのメニューも明朝になる。
- 選択中の項目（foreground）の左端に、3px の目印の帯を置く（クローディアは赤土、アンソニーは藍）。foreground の画像はサイドバーの下に潜らず、そのすぐ右から始まるので、帯は見える（実機で確かめた）。上へ延びても途切れない。
- メニューの端（上下左右）に沿って罫を引かない。枠で閉じていない一本の線は、飾りではなく描画の乱れに見える。メニューの外枠は `frame` の色だけで足りる。

### アイコン（`.ico`）

作るのは `work/icon/make-icon.ps1`（引数なしで `icon.ico` と `icon_anthony.ico` の両方）。

- 大きさは 256 / 48 / 32 / 24 / 16px。
- どの大きさもメダイヨン: 全身の元素材（`work/icon_*_full.png`）から頭のまわりを正方形に切り出し、丸い地（クローディアは羊皮紙、アンソニーは名刺）に収めて輪で囲む。**ティアラと薔薇、ひれと蝶ネクタイとブローチが輪の中に収まるように切り出す**（顔の大写しを丸く切ると、いちばんの目印が切れる）。
- 16px でも同じ図案にする。縮めても輪と顔は見分けられる（エクスプローラーの 16px 表示で確かめた）。大きさによって図案を変えると、ゴーストの印として揃わない。
- 輪の太さは全体の 1/20（少なくとも 1px）。クローディアは金、アンソニーは銀。その外側に深赤土（アンソニーは燕尾）の細い縁を入れ、明るいタスクバーでも暗いタスクバーでも輪が溶けないようにする。輪の外は透明。

### サムネイル、バナー（夜会）

- 描くのは `work/thumbnail/make-thumbnail.ps1`、文言は同じフォルダの `text.txt`（UTF-8）。
- 大きさ: ゴーストのサムネイルは 560×315（16:9）。以前の 720×405 は SSP の中で大きすぎた。バナーも 16:9 を基本にする。
- 配置は 720×405 の座標で決め、書き出す大きさに縮める（`-Width` で変えられる）。細罫だけは、書き出した画像で 1px ちょうどになるように置く。
- 地は夜会の地。人物の後ろに、赤土の光を不透明度 12% ほどの円形のぼかしで置く。
- 枠: 書き出した画像の外周から 9px と 12px の所に、1px の灯の金の二重の細罫。
- 構成: 人物は左の 6 割、文字は右の 4 割。右側は上から、小さな肩書（「悪役令嬢」、灯の金）、題字（「クローディア」、游明朝 Demibold、月明かり、字間 0.12em）、区切りの菱、台詞を 1〜2 行（薄月）、最下段に小さく `伺か ghost / SHIORI: YAYA`（薄月、13px 相当）。
- 右下に小さな封蝋を一つ置く（崩す一か所）。
- 表情は高笑い（5）にする。サムネイルは一枚で名乗る肖像なので、いちばんの象徴を出す（「高笑いは見事に片付いたときだけ」はトークの決まりで、肖像には当てはめない）。
- 台詞は、そのとき新しく書くか、辞書にある台詞から選ぶ。

```powershell

    Vellum = @(250, 245, 234); VellumDeep = @(240, 228, 206); VellumEdge = @(227, 210, 179)

    InkA = @(34, 38, 58); InkASoft = @(74, 82, 112); Blue = @(127, 155, 221)
    BlueInk = @(52, 86, 168); Silver = @(169, 177, 196); Brooch = @(30, 116, 121)

function Get-PaletteColor([string]$Name, [int]$Alpha = 255) {
```

### 絵を頼むとき

立ち絵や挿絵を作者が画像生成で作るときに、画風をそろえる言葉。作者に頼まれたら、この言葉を元にプロンプトを下書きする。

- 光: 窓からのやわらかい午後の光。強い逆光、ネオン、色付きの照明は避ける。
- 色: ivory vellum, terracotta, antique gold hairline, iron-gall ink brown, wine-red wax seal。アンソニーは pale periwinkle blue, black tailcoat, silver tray, teal brooch。
- 質感: 紙と布の手触り。金属の照りは控えめにし、金はつや消し。
- 避けるもの: 純粋な黒の影、ぎらつくハイライト、背景のきらめき、ハートや星の飾り。

## やらないこと

- 金で面を塗る。金の文字を明るい地に置く。
- 純粋な黒と白を使う。
- 赤土の強調を一画面に二か所以上置く。
- ゴシック体でクローディアの台詞を書く。
- 丸いボタン、光る影、ネオン色、きらめきの飾り、絵文字。
- アンソニーの物を、お嬢様の物より華やかにする。
- 色だけで状態を伝える。

## 仕上げの確かめ
