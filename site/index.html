できること

Ce que je sais faire

Claude Code の見張り番

Claude Code があなたの返事や許可を待っていれば、ベルを鳴らしてお知らせしますわ。放っておけば、5 分ごとに念を押して差し上げます。

セッションのファイル（~/.claude/sessions）を見張るだけで、Claude Code の設定には手を触れませんの。通知領域のアイコンも、待ちの有無で切り替わりますわ。

実行中のセッションと、再開、新規起動

メニューの「Claude Code は？」を開けば、今動いているセッションを一覧にしてお見せしますわ。返事待ちを先に並べて、何を待たれているかまで添えますの。

「作業履歴」の頁には、これまでのセッションが題名と日付つきで並びますわ。選べば、そのセッションの作業フォルダで claude -r を開いて、続きから再開できましてよ。

「新規起動」の頁には、これまでに Claude Code を使った作業フォルダが、新しい順に並びますわ。選べば、そのフォルダを作業場所にして claude を新しく始められますの。

最後のメッセージから 1 時間以内なら「温」、過ぎていれば「冷」の印をつけますわ。Claude Code のプロンプトキャッシュは 1 時間ですので、「冷」のセッションを再開すると、キャッシュが残っておらず、会話の全体を読み直すぶん使用量を余計に消費しますの。「冷」の再開は、慎重になさいな。

開けるのは、Claude Code が会話の記録を残しているセッション（既定でおよそ 30 日分）だけ。題名は記録の見出しから拾い、依頼の本文は読みませんわ。今動いているものには印をつけて、二重に開かないようにしてありますの。新規起動に並ぶのは、依頼の履歴（およそ 60 日分）に残るフォルダのうち、今もあるものだけ。Claude Code を動かしていなくても、作業履歴と新規起動は開けますわ。

長いお仕事の完了と、休憩のすすめ

時間のかかった作業が片付けば、ひとことお声がけしますわ。どの作業の話か分かるよう、Claude Code が付けたセッションの題名で呼び、ファイルの手直しやコマンドの数、つまずいた回数まで添えて報告しますの。

続けて 2 時間も働きづめなら、お茶を淹れさせますわ。根を詰めても、良い設計は浮かびませんわよ。

功績録と業務報告

あなたが Claude Code に下した依頼の数、登城した日数、夜更かしの回数まで、わたくしが帳簿につけておきますわ。節目には称号を授けて差し上げますの。

業務報告では、依頼の数、よく働く時刻、治めた領地、Claude が働いた時間を、本日・昨日・今週・先週・今月・先月・今年から選んでまとめますわ。日付を入れて、好きな期間を指定することもできましてよ。

依頼の履歴から読むのは時刻と作業フォルダだけ。依頼の本文は読みませんわ。

お茶とタイマー

メニューの「お茶とタイマー」から、アンソニーに紅茶を頼めば、茶葉ごとの蒸らし時間で砂時計を返しますわ。時間を指定した砂時計も、6 本まで同時に立てられますの。

執務（ポモドーロ）を始めれば、集中と休憩の区切りをお知らせしますわ。集中している間は、わたくしもおしゃべりを控えて差し上げます。分数と本数は「執務の時間割」で変えられましてよ。

お嬢様と執事の掛け合い

ふだんは、わたくしとアンソニーのたわいもない会話。紅茶の品評のような続きものもありますわ。季節の折々や、Claude の誕生日のような記念日には、それにちなんだお話も。

時報

毎時ちょうどに時刻をお知らせしますわ。朝には朝の、お昼にはお昼の、夜更かしには夜更かしのひとことを添えて。15 時は、もちろんお茶の時間ですの。

メニュー

わたくしをダブルクリックすればメニューですわ。話しかける、功績録と業務報告を見る、お茶を頼む、Claude Code の実行中を見て続きを再開する、新しく起動する、設定を変える。最後の行には、今日の依頼の数と待ちの数が出ますの。「さっきの話は？」が出ても出なくても、項目の位置は変わりませんわ。

話しかけ

「名前を覚えて」と話しかければ、呼び方を変えて差し上げますわ。

PC の様子

充電の抜き差し、電池の残り、USB 機器、壁紙の変更、音楽の再生にも気づきますの。

デスクトップの出来事

最小化と復帰、全画面のアプリ、スリープからのお目覚めと画面ロックの解除。邪魔をしないよう、心得ておりますわ。

専用のバルーン

招待状を模した横長・縦長の吹き出しを同梱。ネットワーク更新にも対応していますわ。

お迎えの手順

Comment m'inviter
  1. ベースウェア SSP を用意なさい（Windows 用ですわ）。
  2. claudia.nar をダウンロードなさい。
  3. 起動している SSP のキャラクターに、nar ファイルをドラッグ＆ドロップ。それだけでわたくしが参りますわ。
